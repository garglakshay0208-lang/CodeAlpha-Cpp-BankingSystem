# CodeAlpha-Cpp-BankingSystem
💳 Bank Management System in C++

A console-based Bank Management System developed in C++ using Object-Oriented Programming (OOP) principles. This project simulates core banking operations by enabling users to create and manage customer accounts, perform deposits and withdrawals, transfer funds between accounts, and maintain transaction records. It demonstrates the practical implementation of OOP concepts such as Encapsulation, Abstraction, Composition, and Object Interaction, while utilizing STL containers for efficient data management and transaction tracking.

🚀 Features
Create and manage customers
Create and manage bank accounts
Deposit money into accounts
Withdraw money from accounts
Transfer funds between accounts
View transaction history
Check account balance and details

🛠️ Technologies Used
C++
Object-Oriented Programming (OOP)
Standard Template Library (STL)
Vector Container

📚 OOP Concepts Implemented
Classes & Objects
Encapsulation
Abstraction
Composition
Constructor Initialization
Reference Handling

📂 Project Structure
Customer Class – Stores customer information and account details
Account Class – Handles account operations such as deposits, withdrawals, transfers, and balance management
Transaction Class – Records and displays transaction history

🎯 Learning Outcomes
Applying OOP principles in a real-world application
Managing relationships between multiple classes
Implementing banking operations using C++
Working with STL containers for data storage
Developing structured and maintainable console-based applications
